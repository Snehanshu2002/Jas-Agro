# JAS Agro - Smart Sustainable AgTech Platform

JAS Agro is an advanced agricultural technology platform dedicated to empowering farmers and modern ag-enterprises with sustainable farming systems, smart cultivation labs, and IoT-driven micro-climate automation.

## 🌿 Core Features

- **High-Tech Cultivation**: Automated systems for Oyster Mushroom, Azolla Aquatic Fodder, Hybrid Napier Grass, and Vermicompost.
- **IoT Telemetry & Automation**: Real-time micro-climate monitoring and AI-guided farming assistance.
- **Multilingual Support**: High-performance English & Natural Hinglish localization.
- **E-Commerce Shop Portal**: Gourmet organic produce and precision farming equipment.
- **Interactive ROI & Smart Estimators**: Custom cost-benefit estimators and farm size calculators.

## 🚀 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: Tailwind CSS, Glassmorphism design system
- **Animation**: Framer Motion, Lucide Icons
- **Language**: TypeScript

## 🛠️ Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
